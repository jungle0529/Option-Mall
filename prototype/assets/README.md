# 브랜드 자산 (로고)

옵션몰 헤더 로고는 이 폴더의 파일을 자동으로 사용한다.

## 로고 파일 넣는 법
아래 파일명 그대로 이 폴더에 올리면 헤더에 자동 적용된다(코드 수정 불필요).

1. **`logo-thesharp.svg`** (1순위 · 권장: 벡터, 어떤 해상도에서도 선명)
2. 없으면 **`logo-thesharp.png`** (2순위 · 권장: 배경 투명 + 흰색 로고, 높이 ≥ 52px)
3. 둘 다 없으면 텍스트 폴백("The Sharp")

> 헤더 배경이 짙은 네이비라 **흰색/투명 배경 버전**을 권장. (예시로 받은 회색 배경 PNG는 배경이 같이 보일 수 있음)

## 업로드 방법 (택1)
- GitHub 웹: 이 폴더에서 **Add file → Upload files** 로 로고 파일 업로드 → 커밋
- 또는 파일을 전달해 주면(레포에 커밋 가능한 형태) 직접 반영
- 공개 URL이 있으면 알려주면 내려받아 넣음

권장 사양은 공식 브랜드 가이드(여백·최소크기·색상)를 따른다.

## 평면도 이미지
- **`plan-sample.png`** : 랜딩 조회 결과 카드의 평면도 영역에 **전 타입 공통 샘플**로 표시된다. 이 파일을 올리면 모든 타입에 동일 평면도가 뜬다. 없으면 플레이스홀더 표시.
- 추후 타입별로 분리하려면 `plan-<타입>.png`(예: `plan-118K.png`) 규칙으로 확장 예정.
