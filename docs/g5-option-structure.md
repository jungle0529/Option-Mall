# 더샵 송도그란테르 G5 — 유상옵션 구조 (옵션몰 데이터 기준)

> 버전 v0.1 · 작성일 2026-06-19 · 근거: 입주자모집공고 전문(全文) G5-1블록(gongo_1bl)의 "별도계약 - 추가 선택품목(유상옵션)" 표를 좌표 기반으로 복원
> 가격은 공개 모집공고 기재값(부가세 포함). 단 신문 다단 레이아웃 복원값이므로 최종은 **유상옵션 카탈로그/견본주택과 대조 필요**(공고 본문도 카탈로그 확인을 명시).
> 본 문서는 G5-1블록 기준. 타워(G5-3/4/5/6), G5-11블록은 동일 구조로 별도 표가 있으며 가격만 상이 — 추출 예정.

## 1. 옵션 표 전체 구성 (3개 표)

모집공고의 유상옵션은 세 묶음으로 제공된다. 옵션몰의 옵션 그룹(OptionGroup)이 이 단위로 대응한다.

1. **(1) 시스템에어컨** — 일반형 / 고급형, 설치위치·대수·타입별 가격
2. **(2) 평면/가구(마감재) 등** — 공간(부위)별 핵심 옵션(바닥·거실/복도·다용도실·현관·주방·욕실·드레스룸·거실/침실)
3. **(3) 가전제품 및 설비** — 인덕션·오븐·키친핏·식기세척기·감성조명·전동커튼·에코세이버·욕실복합환풍기 등

납부 구조는 모든 옵션 공통: **계약금 10%(계약 시) / 중도금 10%(2026.10.05) / 잔금 80%(입주지정일)**.

## 2. 공간(부위)별 옵션 taxonomy

### (1) 시스템에어컨
- 기본 제공: 84·102타입 실내기 2개소(거실, 안방) / 124·128·198타입 3개소(거실, 주방, 안방).
- **일반형**: 설치위치·대수별. 예) 84A/B 3대 3,600,000 · 84C 4,000,000 · 102/124/128 3대 4,500,000 · 198PA 4대 7,000,000 · 198PB 5대 7,800,000.
- **고급형**: 기본 제공 일반형 비용을 **차감 산정**. 예) 84 5대 6,000,000 · 102 5대 6,300,000 · 124/128 6대 6,300,000 · 198PA 7대 9,000,000 · 198PB 8대 10,500,000.
- 의존성: **와이드리빙(평면옵션) 선택 시** 설치위치·대수 구성이 달라짐(거실 1대 추가 등).

## 3. 핵심 도메인 규칙 (데이터 모델에 반영)

이 사업지에서 확인된 규칙들. 기획 문서의 데이터 모델을 아래로 확장한다.

1. **평면옵션 종속 (FloorPlanOption dependency)** — 가장 중요. 와이드리빙·평면옵션1/2·듀얼드레스룸·서브마스터·드레스룸 평면변화 등 **평면 자체를 바꾸는 옵션**이 먼저 있고, 거실/복도·주방·드레스룸·조명·에어컨 등 다수 옵션의 **구성·가격·선택지가 이 평면옵션에 종속**된다. (ELIF의 "시그니처 선택 시 활성화"와 동일 메커니즘, 더 복잡한 다단 구조)
2. **브랜드 택1 (brand variant)** — 가전은 삼성/LG 중 택1. 같은 품목에 브랜드별 단가.
3. **기본 차감 정산 (credit against basic)** — 고급형 에어컨, 에코세이버, 욕실복합환풍기 등은 기본 제공품 비용을 **차감**한 금액이 옵션가. 미선택 시 기본형 설치. → 견적 엔진은 단순 가산이 아니라 "기본 제공 대비 델타"로 표현.
4. **상호 의존/배제** — 욕실복합환풍기 ⊃ 전실 시스템에어컨(선결), 에코세이버 선택 시 기본 환기 미시공 등.
5. **납부 분할** — 모든 옵션가는 계약금10%/중도금10%/잔금80% 분할. 옵션몰 견적서는 총액 + 분할 스케줄 표기.
6. **위치 고정** — "설치 위치는 지정되어 있어 계약자가 임의 지정 불가" → 옵션몰은 선택만, 위치 커스터마이즈 없음.

### 데이터 모델 확장 (plan 문서 대비 추가)
```
HousingType
├─ FloorPlanOption[]          (평면옵션1/2: 와이드리빙, 프리미엄키친 평면변화, 듀얼드레스룸, 서브마스터 …)
└─ OptionGroup
   └─ OptionItem
      ├─ priceByType: { [type]: { total, 계약금, 중도금, 잔금 } }
      ├─ brandVariants?: [{ brand, price }]      (삼성/LG)
      ├─ dependsOnFloorPlan?: [평면옵션 조건]
      ├─ requires?: [선결 옵션]                   (예: 전실 시스템에어컨)
      ├─ excludes?: [배타 옵션]
      └─ creditsBasic?: bool                      (기본 차감 정산 여부)
```

## 4. 옵션몰 적용 메모

- VR 타입(84B·124B·118K)은 평면옵션(와이드리빙 등) 선택 시 좌측 VR 씬도 평면 변화를 반영해야 함 → VR 제작 시 평면옵션별 씬 분기 필요(제작 범위 확인 필요).
- image/none 타입은 평면옵션별 결과 이미지 슬롯 또는 텍스트 견적만으로 처리 가능 → 코스트 절감 지점.
- 가전 브랜드 택1, 욕실 단계 선택 등은 좌측 비주얼 변화가 작아 image/none에 적합.
