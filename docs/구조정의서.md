# 더샵 송도그란테르 G5 옵션몰 — 구조 정의서 (디자인 착수 기준)

> 버전 v1.0 · 작성일 2026-08-05 · 이 문서는 Canvas(디자인) 착수 전 **구조 확정본**이다. 화면·상태·데이터·에셋·연동 지점을 모두 고정하고, 디자인은 여기 정의된 슬롯을 스킨하는 방식으로 진행한다.
> 가격·문구는 입주자모집공고 기준(부가세 포함) · 유상옵션 카탈로그 최종 대조 필요(확인 필요).

## 1. 배포 형태 (2종, 동일 데이터·엔진 공유)

| 형태 | 브랜치 | 진입 파일 | 진입 방식 |
|------|--------|-----------|-----------|
| **웹버전** | `claude/gifted-brahmagupta-accsi0` | `prototype/index.html` | 분양 고유번호 조회 → 동호수 → 옵션 |
| **설치형(온라인 키오스크)** | `claude/g5-installer` | `index.html`(루트) | 터치: 블록 선택 → 타입 선택 → 옵션 |

- 좌측 진입부(랜딩)만 다르고, **옵션 선택·견적·데이터 모델은 완전히 동일**.
- 설치형은 이미지·폰트를 로컬 번들(오프라인 폴백), 웹은 조회형.

## 2. 도메인 데이터 모델 (공통)

```
Project(더샵 송도그란테르 G5)
└─ Block(G5-1 / G5-3·4·5·6(타워) / G5-11)
   └─ HousingType(32종)
      ├─ viewerMode : "vr" | "thumb"          # 84B·118K·124B = vr, 그 외 thumb
      ├─ set        : "g5_1" | "tower" | "g5_11"   # 옵션 가격 세트
      └─ fam        : 가격 패밀리 키(84/102/124/128/198 또는 타워 실타입)

OptionSet(g5_1 / tower / g5_11)
├─ pay : 중도금 납부일(그룹별 상이: g5_1·g5_11=2026.10.05, tower=2026.12.28)
└─ OptionGroup[]
   ├─ id/name/space
   ├─ brand? : 브랜드 택1(삼성/LG) 여부
   ├─ requireJeonsil? : 전실 시스템에어컨 선결 필요
   ├─ note? : 그룹 안내
   └─ OptionItem[]
      ├─ id/label/desc
      ├─ p : 가격맵 { <fam>|all : 금액 }  또는 price(브랜드 정액)  또는 "zero"(기본/미선택)
      ├─ jeonsil? : 이 항목이 전실 조건을 만족
      ├─ fp/fpP? : 평면옵션(와이드리빙) 종속 가격 분기
```

### 타입 → 블록/모드/세트 매핑
- **G5-1블록**(set g5_1): 84A **84B(vr)** 84C · 102A~E · 124A **124B(vr)** 124C 124D · 128A~C · 198PA 198PB
- **타워 G5-3·4·5·6**(set tower): 84K **118K(vr)** 129K 188K 198PK  *(4개 블록 가격 동일)*
- **G5-11블록**(set g5_11): 84H 84I 84J · 100A 100B 100C · 124H 124I · 128H · 198PC

### 옵션 그룹(15종, 전 세트 공통 taxonomy)
시스템에어컨 · 바닥마감 · 프리미엄리빙 · 프리미엄키친 · 현관 중문 · 프리미엄바스(욕실1) · 프리미엄바스(욕실2) · 스마트 감성조명 · 전동커튼 · 에코세이버 · 욕실복합환풍기 · 인덕션 3구 · 전기오븐 · 키친핏 냉장고 · 식기세척기

### 옵션 규칙(엔진에 반영됨)
- **델타/기본차감**: 가격은 기본 제공 대비 추가액. 고급형 에어컨·에코세이버·욕실환풍기는 기본품 비용 차감 정산.
- **평면옵션 종속**: 와이드리빙 선택 시 프리미엄리빙 등의 구성·가격 분기(`fp`/`fpP`).
- **브랜드 택1**: 가전 4종 삼성/LG 중 택1.
- **선결 의존**: 욕실복합환풍기 ← 시스템에어컨 [고급형(전실)] 선택 시 활성화.
- **납부 분할**: 계약금10% / 중도금10%(세트별 일자) / 잔금80%(입주지정일).

## 3. 화면·상태 흐름 (State Machine)

### 웹버전
```
[landing: 고유번호 조회]
   └(조회 성공)→ 결과 카드(평면도·타입·모드) →[옵션 선택 시작]→ [options]
[options] →[← 변경]→ [landing]
[options] →[견적서 확인]→ (quote modal)
어디서나 →[가이드]→ (guide modal: 이미지/영상 탭)
```

### 설치형(키오스크)
```
[landing: 조감도 + 블록 2버튼(1·11 / 3~6)]
   └(블록 클릭)→ [types: 해당 블록군 타입 목록]
        └(타입 클릭)→ [options]
[types] →[← 블록 선택]→ [landing]
[options] →[← 변경]→ [types]
[options] →[견적서 확인]→ (quote modal)
[landing] →[가이드 아이콘]→ (guide modal)
```

### 상태 키(설치형 `S`)
`view(landing|types|options)` · `blockGroup(a|b)` · `type/set/fam/mode` · `sel{groupId:itemId}` · `fp{wide}` · `quoteOpen` · `guideOpen/guideTab` · `unit{block,dong,ho,name}`

## 4. 옵션 화면 레이아웃 (모드 분기)
- **vr 타입**: 좌측 = XROO 360 플레이어(풀 높이 sticky), 우측 = 옵션 그룹 세로 나열 + 하단 견적바.
- **thumb 타입**: 단일 컬럼 옵션 그룹 나열(각 그룹 하단에 결과 이미지 슬롯) + 하단 견적바.
- 옵션 카드(리스트형): 체크 + 라벨 + 배지(기본제공/+옵션) + 가격 + 상세설명. 그룹 헤더: 이름 + (단일 선택/브랜드 택1) + 현재 선택 배지.

## 6. API 계약 (웹버전 조회)
```
GET /api/units/{분양고유번호}
→ { block, dong, ho, type, viewerMode, name }
```
예시·목데이터: `prototype/data/units.json`. `G5-<타입>`(예: G5-84A) 입력 시 타입 미리보기.

## 7. VR 연동 지점
- 플레이어: XROO iframe. 현재 샘플 space: `player.xroo.io/space/02f4601f91624c1aa3ef9e8075471d58/...`
- **타입별 실제 space URL 매핑 필요**(84B/118K/124B) → 확정 시 `VR_SRC`를 타입별 맵으로 확장.
- 평면옵션(와이드리빙) 선택 시 VR 씬 분기 여부 = 제작 범위 확인 필요.

## 8. 디자인(Canvas)에서 확정할 항목 — 체크리스트
- [ ] 브랜드 토큰: 정확한 프러시안 블루 hex·서체 규정(현재 accent `#2B3340`, Pretendard)
- [ ] 키오스크 랜딩 비주얼(조감도·블록 버튼 스타일·모션)
- [ ] 타입 선택 화면 레이아웃(그리드/카드)
- [ ] 옵션 카드 최종 스타일(리스트/이미지 배치)
- [ ] 견적서·가이드 모달 스타일
- [ ] 평면도/옵션/가이드 이미지 실제 적용
- [ ] 반응형/키오스크 해상도(가로 FHD 기준) 확정
