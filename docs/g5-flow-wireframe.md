# 하이브리드 옵션몰 — 화면 흐름 & 와이어프레임 (G5 기준)

> 버전 v0.1 · 작성일 2026-06-19 · 대상: 더샵 송도그란테르 G5 하이브리드 옵션몰
> 동작 와이어프레임: `prototype/wireframe.html` (브라우저로 바로 열기, 빌드 불필요)

---

## 1. 정보 구조 (IA)

```
진입(분양 링크/QR)
└─ 사업지(G5)
   └─ 타입 선택            ← 84B(vr) / 84A(image) / 128A(none) …
      └─ 옵션 선택 화면     ← 좌: 비주얼(모드별) / 우: 옵션·견적
         ├─ 공간/그룹 탐색
         ├─ 옵션 선택 → 견적 실시간 반영
         └─ 견적서 확인     ← 선택 내역 + 합계 + 납부 스케줄
```

타입의 `viewerMode`가 좌측 영역을 결정하고, 우측 옵션·견적 UX는 모든 모드에서 동일하다.

---

## 2. 화면 레이아웃 (3분할)

```
┌─────────────────────────────────────────────────────────┐
│ 헤더: 사업지명 · 타입 선택(드롭다운) · 가이드/초기화          │
├──────────────────────────────┬──────────────────────────┤
│ 좌측 VisualArea              │ 우측 OptionPanel          │
│  · vr   → 360 플레이어        │  · 공간/그룹 탭            │
│  · image→ 결과 썸네일(전/후)  │  · 옵션 카드(라디오/택1)    │
│  · none → (숨김, 우측 풀폭)   │  · 가격 델타 표기          │
│                              │  · 의존성 안내(잠금/활성)   │
├──────────────────────────────┴──────────────────────────┤
│ 하단 EstimateBar: 선택 수 · 총 견적 금액 · [견적서 확인]    │
└─────────────────────────────────────────────────────────┘
```

`none` 모드는 좌측을 접고 우측을 풀폭으로 확장(자이 StyleUp형 카탈로그 레이아웃).

---

## 3. 핵심 인터랙션 플로우

1. **타입 선택** → 타입의 `viewerMode`로 좌측 렌더링 결정. 옵션 데이터 세트 로드(g5-1 / g5-tower / g5-11).
2. **옵션 선택(우측)** → ① 견적 재계산 ② 좌측 비주얼 갱신(vr=씬 전환 / image=이미지 교체 / none=없음) ③ 의존 옵션 상태 갱신.
3. **좌측 인터랙션** → vr 모드: 핫스팟 클릭 시 우측 해당 그룹 포커스. image/none: 단방향.
4. **견적서 확인** → 선택 내역·합계·납부 스케줄(계약금10%/중도금10%/잔금80%) 출력.

### 반영해야 할 G5 도메인 규칙 (와이어프레임에 구현)
- **델타/기본 차감**: 옵션가는 기본 제공 대비 추가액. 고급형 에어컨·에코세이버 등은 기본형 비용 차감 정산.
- **평면옵션 종속**: 와이드리빙 등 평면옵션 선택 시 거실/주방/조명/에어컨 옵션의 구성·가격·선택지가 분기.
- **브랜드 택1**: 가전은 삼성/LG 중 택1.
- **선결/배제**: 욕실복합환풍기는 전실 시스템에어컨 선택 시 활성화. 에코세이버 선택 시 기본 환기 미시공.

## 4. 상태 모델 (프론트)

단일 스토어가 좌·우·하단을 동기화한다.

```
state = {
  block, type, viewerMode,
  floorPlan: { 'wide-living': bool, … },   // 평면옵션
  selections: { [groupId]: itemId|null },  // 그룹별 선택
  get total()      // 선택 델타 합
  get isEnabled(groupId)  // 의존성 판정(선결/평면옵션)
}
```

옵션 데이터는 `data/g5-1.example.json` 스키마를 따른다. 좌측 컴포넌트는 `viewerMode`로 교체되는 어댑터.

---

## 5. 와이어프레임 사용법
`prototype/wireframe.html`을 브라우저로 연다. 상단 타입 셀렉터로 vr/image/none 모드 전환을 확인하고, 우측에서 옵션을 선택하면 좌측 비주얼과 하단 견적이 실시간 반영된다. 평면옵션(와이드리빙)·선결(에어컨→욕실환풍기)·브랜드 택1 규칙이 동작한다.

> 본 와이어프레임은 흐름/레이아웃 검증용 저충실도(low-fidelity) 프로토타입이다. 실제 VR 플레이어·이미지·디자인은 별도 단계에서 적용한다.
